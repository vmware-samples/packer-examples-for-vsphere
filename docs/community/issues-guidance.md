## Issues

Use [GitHub issues](https://github.com/vmware/packer-examples-for-vsphere/issues)
to report bugs or suggest enhancements using the
following guidelines.

!!! warning

    Issues that do not follow the guidelines may be closed by the maintainers without
    further investigation.

Before opening an issue, please [search existing issues](https://github.com/vmware/packer-examples-for-vsphere/issues?q=is%3Aissue+is%3Aopen)
to avoid duplicates.

When opening an issue, use the provided issue form to ensure that you provide all the
necessary details. These details are important for maintainers to understand and
reproduce the issue.

!!! warning

    - Ensure that you are using a recent revision of the project.
    - Ensure that you are using supported versions of Packer and VMware vSphere as
      documented in the [environment requirements](../getting-started/requirements.md).
